# **App Name**: Vicious Assistant

## Core Features:

- Voice-Activated Interface: Utilize speech recognition to respond to 'Vicious' or 'Hey Vicious', enabling hands-free command input for the AI assistant.
- Generative AI Assistant Core: Process voice and text inputs using a powerful AI tool (like a fine-tuned LLM) to generate intelligent and contextual responses to user queries and commands.
- Conversation History & Recall: Store past interactions and conversations, allowing the AI to recall previous context and provide continuity across sessions. This will utilize a backend database.
- Personalized Interaction Engine: Customize AI responses based on user preferences and stored profile information, such as the user's name, allowing the AI to address the user personally.
- Image Contextual Analysis: Allow users to capture or upload images from their device's camera, which the AI tool will then analyze to evaluate the 'occasion' and provide contextually relevant suggestions or responses.
- Hands-Free Reminder Management: Enable users to set, view, and manage text-based reminders using voice commands, which the AI tool will process and store.

## Style Guidelines:

- Light/Dark Scheme: Dark.
- Primary color: A vibrant, electric blue (#2896FF) that stands out against the dark interface, signifying intelligence and a cutting-edge feel.
- Background color: A deep, desaturated blue-gray (#1A1F22) for a sleek, modern, and serious backdrop.
- Accent color: A bright aqua (#66F2F2) for contrast and highlighting interactive elements or important information.
- Headlines: 'Space Grotesk' (proportional sans-serif) for a techy, computerized aesthetic. Body text: 'Inter' (grotesque-style sans-serif) for a modern, objective readability in conversation logs.
- Use sharp, minimalist, geometric icons to convey precision and technological sophistication, fitting the cutting-edge AI theme.
- Employ a clean, structured layout with clear visual hierarchy, utilizing ample dark space to focus user attention on AI interactions and responses. Prefer card-based or modular elements for conversational turns.
- Incorporate subtle, fast, and responsive micro-animations for interface feedback, such as typing indicators, response generation, or element transitions, to convey a sense of 'live' and efficient AI processing.
